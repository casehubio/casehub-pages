Component Zod schemas in `pages-schema` are generated by `scripts/generate-schemas.ts` from the TypeScript interfaces in `pages-component`. Never edit `component-schemas.generated.ts` directly — run `yarn workspace @casehubio/pages-schema run generate` to regenerate. A staleness test in `generator.test.ts` compares the committed file against a fresh generation and fails if they differ, ensuring schemas stay in sync with interfaces.
