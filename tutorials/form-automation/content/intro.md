# Form Automation Basics

In this tutorial, you'll automate a simple form using three ARIA commands: `fill`, `select`, and `click`.

**What you'll learn:**
- The structure of a scenario YAML file
- How `fill` targets text fields by role and accessible name
- How `select` targets dropdown menus
- How `click` triggers buttons
- How the scenario controller shows execution progress

**The form** on this page is a "New Team Member" entry form. You'll watch the scenario engine fill it in automatically, with visual feedback highlighting each field as it's targeted.

Use the controller's transport controls to step through the scenario one command at a time, or press play to run it continuously.
